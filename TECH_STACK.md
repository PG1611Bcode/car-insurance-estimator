# Car Intelligence — Tech Stack

## Frontend Technologies
- React (v19.2.4): UI Library for building component-based interfaces
- Tailwind CSS (v3.4.19): Utility-first CSS framework for rapid UI styling
- Vite (v8.0.4): Next-generation frontend build tool
- Framer Motion (v12.38.0): Animation library for smooth UI transitions
- React Router DOM (v7.14.0): Routing library for navigation

## Backend Technologies
- Flask: Lightweight Python web framework serving the API
- Python: Core language for backend logic and AI models

## ML/AI Models
- ResNet-50: Image classification model for 6-class damage categorization
- YOLO: Object detection model for precise damage localization
- Claim Predictor ML: Model to estimate repair cost using tabular claim records

## PDF Libraries
- jsPDF (v2.5.1): Client-side PDF generation for HTML to PDF exporting

## Maps Tool
- Leaflet (v1.9.4): Interactive maps library for finding nearby garages
- React Leaflet (v5.0.0): React components for Leaflet JS integration

## Database & Auth
- Firebase (v12.11.0): Backend-as-a-service for User Authentication and cloud storage

## Dev Tools
- ESLint (v9.39.4): Linter to maintain code quality and styling
- PostCSS: Tool for transforming CSS styles with JS plugins
